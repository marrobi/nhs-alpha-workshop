# Day 2 Issue Templates

This directory is populated at the start of Day 2 by the **NHS Delivery Lead** using the `day2-issue-planning` skill.

The skill uses the actual tech stack, architecture, organisational standards, and codebase from Day 1 to prepare tailored issue templates with precise acceptance criteria.

## How to use

1. Switch to the **NHS Delivery Lead** agent in VS Code
2. Ask it to use `day2-issue-planning` to prepare the Day 2 issues
3. Review the generated files in this directory
4. Confirm before the agent creates issues on GitHub, then assign Copilot to the role agent and skill shown for each issue

See [day2-guide.md](../day2-guide.md) for the full process.
